# UX & UI Design System

The Study Configurator uses a premium **Glassmorphism** design to provide a modern and high-end experience for students.

## Color Palette (CSS Variables)

| Variable | Value | Usage |
| :--- | :--- | :--- |
| `--primary-bg` | `#0f172a` | Deep blue background |
| `--secondary-bg` | `#1e293b` | Card & Section backgrounds |
| `--accent-color` | `#38bdf8` | Primary actions and highlights |
| `--glass-bg` | `rgba(255, 255, 255, 0.05)` | Semi-transparent card layers |
| `--glass-border` | `rgba(255, 255, 255, 0.1)` | Subtle card borders |

## Typography
- **Font Family**: Inter, system-ui, sans-serif.
- **Headings**: Semantic hierarchy (h1-h4) with distinct font weights.

## UI Components
- **Card**: Reusable container with backdrop filter and subtle border.
- **Button-Primary**: High-contrast action button.
- **Badge**: Small info markers for ECTS and codes.

## Accessibility
- Contrast ratios compliant with WCAG AA.
- Visual focus states for keyboard navigation.
- Semantic HTML tags (`<main>`, `<section>`, `<article>`).
